# 🚀 Feature 10: الميزات المتقدمة

> ميزات إضافية تُضاف بعد اكتمال الميزات الأساسية لتحسين تجربة المستخدم وإضافة قيمة للتطبيق.

---

## 📋 ملخص الميزة

| العنصر | التفاصيل |
|---|---|
| **الأولوية** | 🟢 منخفضة (مستقبلية) |
| **التبعيات** | جميع الميزات السابقة (01-09) |

| **التعقيد** | يختلف حسب الميزة |

## ⭐ 10.1: التحميل الدفعي (Batch Download)

### الوصف
تحميل عدة فيديوهات مرة واحدة بلصق عدة روابط أو رابط قائمة تشغيل (Playlist).

### المدة
3-4 أيام

### التفاصيل

#### الملفات
```
lib/features/batch/
├── presentation/
│   ├── pages/
│   │   └── batch_download_page.dart
│   ├── widgets/
│   │   ├── multi_url_input.dart           # حقل متعدد السطور
│   │   ├── batch_preview_list.dart         # معاينة جميع الفيديوهات
│   │   ├── batch_progress_view.dart        # تقدم الدفعة
│   │   └── select_all_quality.dart         # تحديد جودة موحدة
│   └── bloc/
│       ├── batch_bloc.dart
│       ├── batch_event.dart
│       └── batch_state.dart
└── domain/
    └── usecases/
        └── process_batch_urls.dart
```

#### آلية العمل
```
1. المستخدم يلصق عدة روابط (كل رابط في سطر)
2. التطبيق يحللها ويعرض قائمة الفيديوهات
3. يختار الجودة (للكل أو لكل فيديو)
4. يضغط "تحميل الكل"
5. تتم إضافتها في الطابور
```

#### تصور الواجهة
```
╔══════════════════════════════════════╗
║  📦 تحميل دفعي                       ║
╠══════════════════════════════════════╣
║                                      ║
║  ┌────────────────────────────────┐  ║
║  │ الصق الروابط هنا (كل رابط    │  ║
║  │ في سطر جديد):                  │  ║
║  │ https://youtube.com/watch?v=1  │  ║
║  │ https://tiktok.com/@u/video/2  │  ║
║  │ https://instagram.com/reel/3   │  ║
║  └────────────────────────────────┘  ║
║                                      ║
║  تم اكتشاف 3 روابط:                ║
║  ✅ YouTube • ✅ TikTok • ✅ Instagram   ║
║                                      ║
║  الجودة للكل: [720p ▼]               ║
║                                      ║
║  ┌────────────────────────────────┐  ║
║  │     ⬇️  تحميل الكل (3 فيديو)   │  ║
║  └────────────────────────────────┘  ║
║                                      ║
╚══════════════════════════════════════╝
```

#### معايير القبول
- [ ] يقبل عدة روابط (كل رابط في سطر)
- [ ] يحلل كل رابط ويعرض حالته (صالح/غير صالح)
- [ ] يمكن اختيار جودة موحدة أو لكل فيديو
- [ ] يُضيف التحميلات في الطابور
- [ ] يتجاهل الروابط غير الصالحة مع إشعار

## 🎵 10.2: استخراج الصوت (MP3 Conversion)

### الوصف
تحويل أي فيديو إلى ملف صوتي (MP3/M4A/AAC) بجودات مختلفة.

### المدة
2-3 أيام

### التفاصيل

#### الملفات
```
lib/features/download/
└── data/
    └── services/
        └── audio_extractor.dart         # استخراج الصوت
```

#### الخيارات
- **الطريقة 1: من الـ Backend** — السيرفر يرجع رابط صوت مباشر (أسهل ✅)
- **الطريقة 2: محلي** — تحويل بعد التحميل باستخدام `ffmpeg_kit_flutter`

#### الجودات
| الجودة | الوصف | الحجم التقريبي (دقيقة) |
|---|---|---|
| 128 kbps | عادية | ~1 MB |
| 192 kbps | جيدة | ~1.5 MB |
| 256 kbps | عالية | ~2 MB |
| 320 kbps | ممتازة | ~2.5 MB |

#### معايير القبول
- [ ] يمكن التبديل لوضع "صوت فقط" في صفحة المعاينة
- [ ] جودات الصوت تظهر بدلاً من جودات الفيديو
- [ ] الملف يُحفظ بصيغة MP3
- [ ] حجم الملف المتوقع يظهر قبل التحميل

## ▶️ 10.3: مشغّل فيديو مدمج

### الوصف
مشغل فيديو داخلي يسمح للمستخدم بمشاهدة الفيديو قبل التحميل أو بعده.

### المدة
2-3 أيام

### التفاصيل

#### الملفات
```
lib/features/player/
├── presentation/
│   ├── pages/
│   │   └── video_player_page.dart
│   └── widgets/
│       ├── video_controls.dart
│       ├── progress_slider.dart
│       └── fullscreen_button.dart
└── domain/
    └── usecases/
        └── play_video.dart
```

#### الحزم
- `video_player` أو `chewie` للتشغيل
- دعم التشغيل من رابط (URL) ومن ملف محلي

#### المميزات
- تشغيل / إيقاف
- شريط تقدم قابل للسحب
- العرض بملء الشاشة (Fullscreen)
- التحكم في السرعة (0.5x, 1x, 1.5x, 2x)

#### الاستخدام
```
من صفحة المعاينة: زر "▶️ تشغيل" فوق الصورة المصغرة
من السجل: الضغط على "فتح" → تشغيل الملف المحلي
```

#### معايير القبول
- [ ] يشغل فيديو من URL
- [ ] يشغل فيديو محلي
- [ ] أزرار التحكم تعمل
- [ ] Fullscreen يعمل
- [ ] تغيير السرعة يعمل
